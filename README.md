# Spencio plugins for Claude Code

The marketplace for [Spencio](https://spencio.blocmind.tech), the expense tracker. It has one plugin, [`spencio`](plugins/spencio), which connects Claude Code to your Spencio data through Spencio's MCP mode.

```bash
claude plugin marketplace add BlocMind/spencio-claude-plugin
claude plugin install spencio@spencio-plugins
```

Then start MCP mode in the Spencio app on your phone, run `/mcp` in Claude Code, choose `plugin:spencio:spencio` and type the code your phone shows. Full setup: [spencio.blocmind.tech/ai-assistants](https://spencio.blocmind.tech/ai-assistants).
